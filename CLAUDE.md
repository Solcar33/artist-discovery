# Projet artist-discovery

## Contexte
Projet d'apprentissage d'un développeur junior (< 2 mois d'expérience).
Objectif : chaque semaine, recommander un nouvel artiste à partir de
l'historique Spotify de l'utilisateur et publier une page de type blog.

## Règles de collaboration
- Guider étape par étape. Ne jamais tout faire à la place de l'utilisateur.
- Expliquer le POURQUOI de chaque commande et de chaque choix.
- Utiliser un vocabulaire simple ; définir tout terme technique à sa première apparition.

## Notes automatiques
- Après chaque étape validée, proposer une entrée pour `notes.md`
  au format : Ce que j'ai fait / Pourquoi / Commande ou code clé /
  Ce que j'ai appris / Question restante.
- L'utilisateur relit et reformule avec ses mots avant de commiter.

## Conventions
- Python 3.15, environnement virtuel `.venv`, branche `master`.
- Données personnelles dans `data/` : jamais commitées.
- Clés API dans `.env` : jamais commitées.
- Messages de commit : `type: description` (chore, feat, fix, docs).
